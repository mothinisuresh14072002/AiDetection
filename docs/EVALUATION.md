# Evaluation protocol

A detector is not considered production-ready from accuracy on one dataset.

For each modality, evaluate on held-out real media and multiple synthetic-generation families. Report precision, recall, F1, ROC-AUC, PR-AUC, calibration error, false-positive rate, compression/resolution robustness, and subgroup performance where legally and ethically appropriate.

Publish dataset licenses, generator coverage, preprocessing, thresholds, confidence intervals, and known failure modes. Never report a single universal accuracy number.
